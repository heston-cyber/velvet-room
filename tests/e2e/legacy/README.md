# Legacy browser tests (v1, Oct 14 to 16)

These drove the first version of the game: the separate `/tv` window, the old host laptop menu and Live tab, and the
character sign-up form (made-up names, signatures, weapon picks). All three are gone (the host screen is the TV since
v2; sign-up is face and real name since Oct 18), so these no longer run. Moved here on Oct 21 (Phase 8) rather than
deleted, for reference.

What covers the same ground now: `solo.py` (a full night with bots), `framed.py`, `timed.py`, `runoff.py`, `votes.py`,
`phones.py` (every phone tab at three sizes), `screens.py` (every TV screen), `show.py` (How to play, the intro, the
roll call), `join.py`, `signup.py`, `lobby.py`, `cast.py`, `host_start.py`, `host_pages.py`, `no_accomplice.py`,
`phone_fixes.py` and `jokes.py`.
